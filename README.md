# Coming Soon Page

A single-page "Coming Soon" placeholder template built with pure HTML and CSS.  
Perfect for temporarily filling a website that's still under development.

## 📋 Description

The page displays a centered **"Coming Soon"** heading with a shimmering gradient effect and a smooth fade-in animation.  
No external libraries, fonts, or frameworks required — it works out of the box.

## ✨ Features

- Minimalist dark design (`#0d0d0d`)
- Animated text appearance (`fadeIn`)
- "Running" gradient effect across the letters (`shine`)
- Responsive: font size and letter spacing shrink on screens up to 600px wide
- Single file — easy to drop into any project

## 🚀 Usage

1. Copy the code into an `index.html` file.
2. Open the file in your browser — done.

Or paste the contents of `<body>` and `<style>` into an existing page.
